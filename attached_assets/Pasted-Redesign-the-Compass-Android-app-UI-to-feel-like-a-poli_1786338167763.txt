Redesign the Compass Android app UI to feel like a polished, production-ready mobile application, not a web landing page.

IMPORTANT: Keep the existing Compass functionality and architecture intact. Improve the UI/UX rather than rebuilding unrelated parts.

1. OVERALL MOBILE DESIGN
- Design specifically for Android phone screens and portrait orientation.
- The current UI feels cramped and too much like a desktop/web landing page.
- Rework spacing, typography, sizing, alignment, and visual hierarchy throughout the home screen.
- Make the interface clean, modern, premium, and easy to use with one hand.
- Use consistent margins and padding.
- Avoid oversized text that gets cut off or wraps awkwardly.
- Make every section feel intentionally designed for a mobile app.
- Keep the Compass visual identity: navigation, discovery, exploration, and subtle blue/purple accents.
- Do not make everything glow or look overly futuristic. Keep it professional.

2. TOP NAVIGATION
Redesign the top bar:
- Compass logo/icon on the left.
- "Compass" beside it with clean professional typography.
- "Get Started" on the right as a properly sized rounded button.
- Make sure the button is completely visible and never clipped on smaller phones.
- Give the header proper spacing and elevation/separation from the content.
- The header should feel like a real Android app toolbar.

3. GET STARTED BUTTON — MUST WORK
The "Get Started" button must be functional.

When the user taps "Get Started":
- Navigate to an authentication screen.
- The authentication screen should clearly offer:
  - Sign In
  - Create Account / Sign Up
- Make the two actions visually distinct.
- Include appropriate input fields for email and password.
- Include a "Forgot password?" option on the Sign In screen.
- Include a clear way to switch between Sign In and Sign Up.
- Add proper validation and friendly error messages.
- Do not leave the button as a decorative element.
- Use smooth native-feeling transitions between Home → Authentication → Sign In/Sign Up.

4. HERO SECTION
Redesign the current "Find. Compare. Decide." section.

The current hero is too tall and crowded on mobile.

Create a more balanced mobile hero:
- Keep the Compass message and branding.
- Use a strong but appropriately sized headline.
- Make "Find. Compare. Decide." fit naturally on the screen without awkward clipping.
- Reduce unnecessary vertical space.
- Make the supporting text shorter and easier to read.
- Keep the AI-powered local discovery concept.
- Make the search experience the primary interactive element.

5. SEARCH
Make the search bar feel like a real mobile search experience:
- Full-width with comfortable touch height.
- Clear search icon.
- Proper placeholder text.
- Functional search interaction.
- Search button should be visually integrated rather than squeezed against the edge.
- Add subtle focus/press states.
- Keep suggested searches, but present them as clean horizontally scrollable chips rather than cluttering the hero.

6. CATEGORIES
Redesign "Popular categories".

Current category cards look too large and empty.

Create compact, attractive category cards with:
- Better icons instead of plain letters such as R, C, B, S.
- Restaurant
- Café
- Bar
- Retail
- Consistent icon treatment.
- Clear category name.
- Subtle color differentiation.
- Consistent card dimensions.
- Proper touch feedback.
- Cards should feel like actual Android UI components.

7. FEATURED BUSINESS CARDS
This is especially important.

The business cards should visually showcase the businesses rather than just showing text.

Each business should have:
- A real business image/photo.
- Business name.
- Category.
- Rating.
- Review count.
- Location.
- Short description when appropriate.
- Favorite/heart button.
- Clean image with rounded corners.
- Proper image cropping using a consistent aspect ratio.
- Professional typography and spacing.

Do NOT use random placeholder images if real business images are already available in the project.

If the project currently contains business image URLs/assets, use them properly.
If images are missing, structure the data/model so real business images can easily be added later.

8. BUSINESS DETAIL EXPERIENCE
When a business card is tapped:
- Open a dedicated business detail screen.
- Show a large business photo at the top.
- Show name, category, rating, reviews, location, description, and other available information.
- Include useful actions such as:
  - Save/Favorite
  - Call
  - Directions
  - Website, if available
- Make this screen feel like a real local-discovery app.

9. HOME SCREEN HIERARCHY
The home screen should feel like this:

Top bar
↓
Short, attractive discovery hero
↓
Search
↓
Suggested searches
↓
Popular categories
↓
Featured businesses
↓
More businesses / browse section

Do not try to fit everything above the fold.
It is completely fine for the user to scroll.

10. ANIMATIONS
Keep the existing Compass startup animation.

The startup sequence should remain:

Android launch screen
→ Compass launch animation
→ Home screen

Make transitions smooth and intentional.

For the HOME SCREEN:
- Use subtle entrance animations.
- Cards can fade/slide into place.
- Avoid excessive animation.
- Animations should feel premium and fast.
- Respect Android reduced-motion/accessibility settings.

11. LOADING STATES
Replace generic-looking loading behavior with a polished Compass loading experience.

When business data is loading:
- Use attractive skeleton cards or a subtle Compass-themed loading indicator.
- Never leave the user staring at a blank screen.
- Avoid the plain white/grey loading screen appearing between screens.
- Loading should feel intentional and consistent with the Compass brand.

12. RESPONSIVE AND ANDROID QUALITY
Test the layout for common Android phone sizes.
Make sure:
- Nothing is clipped.
- Text never runs outside the screen.
- Buttons are fully tappable.
- Content respects the status bar and navigation areas.
- Images maintain correct proportions.
- Scrolling works naturally.
- Keyboard does not cover authentication fields.
- Touch targets are large enough.
- The UI looks good on both smaller and larger Android phones.

13. VISUAL DIRECTION
The final design should feel closer to a professional app such as a modern local-discovery/productivity application.

Aim for:
- Clean
- Premium
- Modern
- Minimal
- Confident
- Mobile-first
- Easy to navigate

Avoid:
- Overly huge typography
- Excessive gradients
- Excessive neon/glow
- Crowded sections
- Empty oversized cards
- Desktop/web-style layouts
- Clipped buttons
- Placeholder-looking UI

Most importantly, do not simply adjust a few CSS values. Re-evaluate the visual hierarchy and component layout so the entire Home screen feels intentionally designed for Android.

After implementing the redesign, run/build the app and verify the complete flow:

Launch screen
→ Compass animation
→ Home
→ Get Started
→ Sign In / Sign Up
→ Return to Home
→ Search
→ Category
→ Business card
→ Business detail

Fix any visual or navigation issues you find during testing.
